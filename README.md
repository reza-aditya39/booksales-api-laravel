# Booksales API (Laravel)

RESTful API untuk manajemen data buku (*Books*) dan penulis (*Authors*) yang dibangun menggunakan framework Laravel. Proyek ini dikembangkan sebagai bagian dari tugas Studi Independen Fullstack Web Development — NF Academy.

## Tech Stack
* **Framework:** Laravel (PHP)
* **Database:** SQLite / MySQL (Laragon)
* **API Testing:** Postman
